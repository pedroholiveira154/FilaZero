# O que é a pasta private?

A pasta `private/` contém páginas que usuários comuns não conseguem acessar normalmente, sendo ,no momento, a página de **Estoque** que tem todos os produtos que estão no Banco de Dados e suas respectivas ações como:

- Atualizar
- Excluir
- Adicionar
- E etc...

Ou seja, a página de administrador.

**IMPORTANTE**

No momento é necessário criar o administrador via script no CMD. Dentro da pasta `server-mysql/`, digite:

- node criar-admin.js
